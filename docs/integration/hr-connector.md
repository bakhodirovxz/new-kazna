# HR API — инструкция администратора

API: `https://hr-api.uzgidro.uz` (без `/api/v1`), только чтение (GET), авторизация заголовком
`X-Api-Key`. Описание методов — `/directory/structure` и `/directory/attendance`
(`docs/integration/hr-sorov-s4.md`).

1. Адрес и ключ вводятся в панели: «Администрирование → Интеграции → Кадровая система (HR API)»
   (Изменить → причина + код 2FA → Проверить подключение). Адрес `hr.base_url` — только
   `https://` (по умолчанию `https://hr-api.uzgidro.uz`), секрет `hr.api_key` («API-ключ HR»)
   хранится зашифрованным; в файлах, `prod.env`, Docker secrets, журналах и браузере его нет.
   Проверка подключения запрашивает `/directory/structure?include_empty=false` (без ФИО). При
   корпоративном сертификате — файл CA `HR_CA_FILE` (по умолчанию `/run/secrets/hr_ca_bundle`).
2. Если имя `hr-api.uzgidro.uz` не разрешается DNS внутри сети, адрес закрепляется файлом
   `deploy/compose.override.yml` (сертификат по-прежнему проверяется по имени):
   ```yaml
   services:
     worker:
       extra_hosts: ["hr-api.uzgidro.uz:10.0.0.10"]
   ```
3. Сопоставление организаций HR и филиалов (по `hr_id` — он стабилен; имя в HR может содержать
   искажённые символы и используется только как запасной вариант). Готовое сопоставление для
   филиалов демо — `docs/integration/hr-orgs.example.json`:
   ```bash
   docker compose -f deploy/compose.prod.yml exec worker \
     python -m app.cli hr-orgs --file /data/inbox/hr_orgs.json
   ```
   Без `--file` — показать текущее сопоставление. Каждое изменение — новая версия и запись аудита.
   Не вошедшие в список организации (дочерние общества, Норин и Камчик без филиала в системе)
   пропускаются с одним предупреждением `unmapped_org` (количество и `id`).
4. Проверка: `python -m app.cli hr-check` (0 — доступен, 1 — ошибка, 2 — не настроен).
5. Численность — ежедневно в 06:30 (`etl.hr_cron`): `/directory/structure?include_empty=false`,
   по каждому филиалу сумма сотрудников по категориям (rahbar — «Руководители», mutaxassis —
   «Специалисты», xizmatchi — «Служащие», ishchi — «Рабочие», без категории — «Без категории»).
   Штатная численность, приём/увольнение и сверхурочные в этом API отсутствуют (штат — из файлов,
   `docs/integration/kadry-fayl.md`; ФОТ — из денежных потоков 1С).
6. Явка — `/directory/attendance?size=1&include_days=false`: за сегодня каждые 10 минут с 07:00
   до 20:50 (`hr.attendance_cron`), вчерашний день перезагружается ночью
   (`hr.attendance_nightly_cron`). Сохраняются только счётчики по филиалу и статусу; список
   `items` (с ФИО) не читается и не сохраняется. Данные старше `hr.attendance_stale_minutes`
   помечаются в «Кадры → Сводка → Явка сегодня» как устаревшие. Пока ключ не введён, опрос
   пропускается без ошибок.
7. mehnat.uz — этап 3 ТЗ: источник `mehnat` пока «не настроен».
