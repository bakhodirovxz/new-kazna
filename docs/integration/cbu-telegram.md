# Курсы ЦБ РУз и Telegram-бот — инструкция администратора

## Курсы ЦБ (cbu.uz)
- Источник: `https://cbu.uz/ru/arkhiv-kursov-valyut/json/all/<ГГГГ-ММ-ДД>/` — курс, действующий в
  этот день (в выходные — установленный ранее). Хранится по каждому календарному дню (`dwh.fx_rate`).
- Включение: «Администрирование → Интеграции → ЦБ РУз: курсы валют» → «Изменить» (причина и код
  2FA) → `cbu.enabled` = включено → «Проверить подключение». При необходимости задайте
  `EGRESS_PROXY` в `prod.env` (см. `docs/ops/host-hardening.md`). Задание `etl_cbu` — ежедневно в 08:00 (`etl.cbu_cron`), каждый раз
  запрашиваются последние `fx.lookback_days` (7) дней, пропуски заполняются сами.
- Валюты: настройка `fx.currencies` (по умолчанию USD, EUR, CNY, RUB, GBP, JPY, CHF, KZT, KRW).
- История (один раз, до 800 дней за запуск):
  ```bash
  … run --rm worker python -m app.cli cbu-backfill --from 2024-01-01 --to 2026-03-10
  … run --rm worker python -m app.cli cbu-backfill --from 2026-03-11 --to 2026-09-25
  ```
- Курс нужен: кредитному портфелю (сумовой эквивалент на отчётную дату) и валютным счетам в
  выписках. Если курса нет, кредит помечается «нет курса ЦБ», валютная выписка не загружается.

## Telegram-бот (исходящие сообщения)
1. Создать бота у @BotFather, добавить его в рабочую группу, узнать id чата (для групп — отрицательное).
2. «Администрирование → Интеграции → Telegram-бот» → «Изменить» (причина и код 2FA): токен бота
   и список id чатов (`telegram.chat_ids`). Токен хранится зашифрованным (AAD), не показывается в
   интерфейсе и не попадает ни в журналы, ни в сообщения об ошибках. Файлов-секретов Docker и
   перезапуска не требуется — настройка читается при каждой отправке. Без токена или чатов
   Telegram выключен.
3. Проверить: «Проверить подключение» (метод `getMe`, сообщение не отправляется) или `… run --rm worker python -m app.cli telegram-test`
   (0 — отправлено во все чаты, 1 — ошибка отправки, 2 — не настроено);
   `telegram-test --summary` — отправить дневную сводку сейчас.
4. Что приходит (по умолчанию **ничего**: `telegram.summary_scope = off`, `telegram.forward_alerts` выключено):
   - `telegram.summary_scope = org_totals` — ежедневно в 08:30 (`telegram.summary_cron`) сводка только по
     организации: остаток, поступления и расходование с начала месяца, платежи на 14 дней и покрытие,
     кредитный портфель и ближайший платёж, курсы USD/EUR, **число** сработавших правил «Требует
     внимания». Строк по филиалам, наименований контрагентов, номеров счетов и названий правил нет.
     Суммы — в млрд/трлн сум. Каждая отправка записывается в журнал аудита (`notify.telegram.summary`).
   - `telegram.forward_alerts` — ошибки загрузок, проверки качества, устаревание данных, отклонённые
     строки выписок: только заголовок, без сумм и названий.
5. Передача данных во внешний сервис включается только после письменного согласия заказчика / ЦСК
   (см. `docs/security/data-classification.md`, раздел 4); пока согласия нет, оставьте `off`.
